# 數學 × JoJo 第四部 章節與劇情對應表

> 依據:[01-高一數學課程大綱](01-高一數學課程大綱.md)(9 個「章」、54 個子主題)與 [02-JoJo第四部劇情](02-JoJo第四部劇情.md)(13 個不可改動結果節點 J1~J13)。
> ⚠️ 劇透警告。這是**設計稿**:每個劇情段落的「結果」必須對應 J 節點(原作一致),「包裝/梗」可自由發揮、越無厘頭越好。
> 版權:全部用自己的話與原創梗;**不抄台詞、不用原作圖**;素材規範見 [CLAUDE.md](../CLAUDE.md)「素材規範」。

## 1. 規則

1. **每過一關(一小段)就給一張圖 + 一小段文字,推進一點劇情**(可選音效);一個子主題的各關畫面連起來 = 本表的那一段劇情,**結果句放最後一張**。沒有 XP、星星、血條、等級、頭像、暱稱;**過關的回饋就是看劇情的無厘頭發展**。
2. **每章 Boss 關** 通過 → 該章「大事件」劇情(章節高潮,對應 J 節點的收束)。
3. 劇情「段落」總數 = 54(子主題)+ 9(Boss)+ 1(終章)= **64 段**;每段拆成 3~5 張畫面(依該子主題關卡數),**畫面總數約等於關卡總數(約 206 張)**。劇情依原作時間順序排列,所以**章序即劇情序**。
4. **結果不能改、過程隨便改**:誰死/誰加入/誰擊敗誰以 J 節點為準;地點、招式、動機、對話全部可以荒謬化。
5. **劇情不要幫忙解題**:劇情是獎勵,不是教學;數學梗只做「包裝」,題目本身必須無歧義。
6. 最終戰(第 8 章)的**詳細過程**各來源不一致(見 02 待確認),故第 8 章只鎖定結果節點,過程完全自編。
